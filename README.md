# Курьерская служба доставки

Учебный проект на JavaScript (Node.js): обработка заказа и выбор способа доставки в зависимости от веса и расстояния. Цель проекта — закрепить на практике паттерны проектирования и принципы ООП.

## Использованные паттерны

- **Стратегия** (`src/strategies`): у каждого способа доставки свой алгоритм расчёта стоимости, а общий интерфейс `calculate(order)` задаёт базовый класс `DeliveryStrategy`.
- **Фабричный метод** (`src/factories`): фабрика по весу и расстоянию выбирает подходящую стратегию. Вся логика выбора находится только в фабриках.
- **Внедрение зависимостей**: `OrderProcessor` получает фабрику через конструктор и ничего не знает о конкретных стратегиях. Благодаря этому одну и ту же логику обработки заказа можно использовать с разными фабриками (дневной и ночной).

## Способы доставки

| Способ | Условие (дневная фабрика) | Стоимость |
|--------|---------------------------|-----------|
| Дрон | до 2 кг и до 5 км | 700 + вес × 2 + расстояние × 1 |
| Велокурьер | до 5 кг и до 10 км | 100 + вес × 5 + расстояние × 1 |
| Авто | до 30 кг и до 45 км | 200 + вес × 8 + расстояние × 3 |
| Фура | всё остальное | 500 + вес × 10 + расстояние × 6 |

Ночная фабрика (`NightDeliveryFactory`) доставляет только дроном. Если заказ не подходит, выбрасывается ошибка.

## Обработка ошибок

`OrderProcessor` проверяет входные данные: вес и расстояние должны быть числами больше нуля. При некорректных данных выбрасывается `Error` с описанием проблемы, которую можно перехватить через `try / catch`.

## Структура проекта

```
.
├── main.js                       # точка входа, примеры заказов
├── package.json
└── src
    ├── OrderProcessor.js         # обработка заказа
    ├── factories
    │   ├── DeliveryFactory.js
    │   └── NightDeliveryFactory.js
    └── strategies
        ├── DeliveryStrategy.js   # базовый класс
        ├── BikeDeliveryStrategy.js
        ├── CarDeliveryStrategy.js
        ├── DroneDeliveryStrategy.js
        └── TruckDeliveryStrategy.js
```

## Запуск

Нужен установленный [Node.js](https://nodejs.org/).

```bash
git clone https://github.com/squuuuuueeeeezzzzzz/delivery-patterns.git
cd delivery-patterns
node main.js
```

## Пример

```js
const processor = new OrderProcessor(new DeliveryFactory());

console.log(processor.process({ weight: 20, distance: 45 }));
// { order: { weight: 20, distance: 45 }, delivery: { type: 'Авто', cost: 495 } }
```
